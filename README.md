# 伍子平 · 星火远征

仓库里现在有两样可以装到手机上的东西：原来的离线像素 RPG，以及手机工作台「天工」。天工的上课模式、离线 Python 和覆盖安装写在 [天工使用与安装说明](studio/README.md)。那份说明仍按 0.1.12 列举安装包，`dist/` 里没有这些文件；版本、下载和 0.1.13 之后的改动以本文为准。

当前源码版本：游戏 `app/build.gradle` 为 **0.7.1**（versionCode 8），天工 `studio/build.gradle` 为 **0.1.14**（versionCode 22）。已经放进 `dist/` 的包是游戏 0.7.1 和天工 0.1.13，还没有名为 0.1.14 的 APK。0.1.14 的界面改动只在源码里。

[下载游戏 v0.7.1](dist/WuziPing-Emberbound-0.7.1-debug.apk) · [下载天工 0.1.13](dist/Ember-Studio-0.1.13-debug.apk) · [下载仓库源码 ZIP](https://github.com/ohGGBob/WuziPingRPG/archive/refs/heads/main.zip)

校验和：`dist/SHA256SUMS.txt` 只覆盖 0.7.1 的标准包和共存包，`dist/STUDIO-SHA256SUMS.txt` 只覆盖天工 0.1.13 的两个包。游戏旧包 0.1.0–0.7.0 仍在 `dist/`。`tools/package-source.py` 的目标是 `dist/WuziPingRPG-0.7.0-source.zip`，`tools/package-studio-source.py` 的目标是 `dist/Ember-Studio-0.1.12-source.zip`，这两个压缩包目前都不在仓库里。

仓库包含源码、角色与场景素材、构建脚本、验证记录和 APK。签名私钥、构建缓存、本地玩家存档及重复源码压缩包不纳入 Git。GitHub 仓库已公开，可直接查看和下载。

版本 **0.7.1**。离线单机、2D 俯视角像素 RPG，在 0.7.0「规律星庭」上增加物理工坊。主角默认叫伍子平，在主界面可改成喜欢的名字。中山大学仍是 1440×1080。右侧主题地图还是身体和数学两张；物理不在这张星图上，从城内格物堂进入。身体保留八处器官副本，数学仍是三幅 1536×1152 的探索地图，物理是另外五幅同尺寸的机关图。

0.7.0 起，几何与拓扑规则变成实际走位机关：等距花园、七桥星庭、翻向长廊。观察机关反馈、尝试不同路径，找到规律才能通关；通关后札记才会说明原理。数学主题没有答题弹窗或战斗怪物，当前为本地编写的三关探索原型。

人体篇提高了敌人生命、追击速度、刷新密度和首领攻击节奏。武器增加围绕握点的实际旋转、长枪突刺及远程后坐，拖尾随挥动方向变化；暂停菜单可切换标准/柔和特效。人体图统一按原图比例居中绘制。

## 安装与开始

- 游戏 Android：`dist/WuziPing-Emberbound-0.7.1-debug.apk`，最低 Android 6.0 / API 23，横屏。包内版本名是 0.7.1，标准包名 `cn.wuziping.ember`，versionCode 8，沿用本地 0.5 开发密钥。
- **若已安装外部 0.6，请下载 `dist/WuziPing-Emberbound-0.7.1-parallel-debug.apk`。** 它使用 `cn.wuziping.ember.preview07`，桌面名称带「0.7试玩」，可与旧版共存，独立建立新存档，不会自动导入旧版进度。外部 0.6 与标准包签名不同，不能直接覆盖；不要为试玩而卸载旧版丢失数据。已装过 0.7 共存包的，可以用这个 0.7.1 共存包覆盖。
- 同目录里的 `WuziPing-Emberbound-0.7.0-debug.apk` 在物理工坊那次提交里重新打过，包内版本名仍是 0.7.0，但已经包含物理工坊和下面的试玩触控改动。`WuziPing-Emberbound-0.7.0-parallel-debug.apk` 没有重打，仍然是不含物理工坊、也不含「点面板外继续」的 0.7.0 共存包。要玩当前内容，安装 0.7.1。
- 天工 Android：`dist/Ember-Studio-0.1.13-debug.apk`（`cn.wuziping.ember`，桌面名「天工」）和 `dist/Ember-Studio-0.1.13-parallel-debug.apk`（`cn.wuziping.ember.preview07`，桌面名「天工 · 试玩」）。包内版本名是 0.1.13。选与手机上已有天工或 0.7 相同的包名直接覆盖，编辑器成为首页，原 `journey-v1.bin` 继续留着；不要先卸载。外部 0.6 的证书不同，标准包盖不上去。更早的 `dist/Ember-Studio-0.1.2-*.apk` 只有当时的编辑器和游戏入口，没有上课模式，也没有物理工坊。
- 点击「开启体内远征」，阅读梦境剧情，靠近广场北侧沈砚接取任务，再走到北门血管入口出发。
- **已有 0.1/0.2 存档会继续原森林剧情。要体验身体、数学或物理新篇章，请返回主界面，选择「开启新的远征」并确认。此操作会重置当前旅程。**
- 0.3 旧存档可直接继续：回到中山大学即可寻找新增伙伴，无需新开旅程。0.1/0.2 的城镇剧情也支持本次隐藏相遇。格式 1–5 不经过 `readProfileExtras`，物理进度按未开始处理。格式 6 及本次写入的格式 7 会在读完数学、物理之后再读一遍，和写入顺序不一致，见下文存档一节。换包之前先备份存档。
- 桌面调试：`java -jar dist/WuziPing-desktop-preview.jar`，Java 8 以上。这个 jar 含试玩之后的暂停菜单和更大的战斗按钮，不含 `PhysicsJourney`，桌面不播放 Android 音效。

## 数学主题与名字

在城镇点击右侧「主题地图」并选择数学，或沿东边小路走到「数学之门」。学者知夏也会告诉你方向。无需先完成身体主线。探索中从光门或暂停菜单回城，再切换主题；敌人、弹丸和空投会冻结，身体战斗进度保留。

| 地图 | 玩家要做的事 | 首次奖励 |
| --- | --- | --- |
| 等距花园 | 观察三盏灯与地面轨迹，寻找不会让灯熄灭的连续路径 | 60 金币、生命上限 +8 |
| 七桥星庭 | 在桥和节点之间规划一条不重复的完整路线 | 80 金币、生命上限 +8 |
| 翻向长廊 | 观察穿过接缝后的位置、箭头与路标反应 | 100 金币、生命上限 +8 |

三关依次开放，重复停留、重启或再次进入不会重复领奖。右侧缩略图帮助定位，地面保留近期脚印；「重走」只重置当前未完成机关。已解开的原理在札记中回看。长廊是两端反向粘合的理想化接缝模型，箭头表示局部坐标朝向，不表示莫比乌斯带有两张面。

主界面点击「修改名字」：最多 12 个 Unicode 字符，留空恢复「伍子平」。HUD、人物名牌、对话及新旅程沿用所选名字，写入本地存档。

## 天工

天工是可安装的 Android 工作台，不是 VS Code 移植。界面用 CodeMirror 6，Python 用打进 APK 的 Pyodide 0.27.7 / CPython 3.12.7，运行资源都在包内。启动页用滑动、滚轮、方向键或点按，在四个模式里选一个。

| 模式 | 打开之后 |
| --- | --- |
| 写 Python | 多文件编辑，离线运行。工作区自带 `main.py`、`geometry.py`、`data.json`、`index.html`。JavaScript 在独立线程里跑，HTML 有单独的预览页。C/C++、Java、TypeScript 只有高亮 |
| 普通记事本 | 打开 `笔记.txt`，藏起运行、行号和文件标签，草稿仍自动保存。0.1.14 源码在这个模式的顶栏加了画笔 |
| 游戏 | 进入原来的原生画面。《星火远征》存档沿用。游戏里按 Android 返回键可以选择「保存并返回编辑器」；标题界面按返回键直接回编辑器。娱乐区可以导出、导入 `.wzpsave` |
| 上课 | 录音、时间戳笔记和 PPT 照片放在同一条时间轴上。点一行笔记，音频跳到当时，并显示对应的 PPT。详见 `studio/README.md` |

上课模式用 WebView 的 `getUserMedia` 和 `MediaRecorder`（webm/opus），单次最长 2 小时。Android 端在第一次录音时申请 `RECORD_AUDIO`。能量 VAD 会自动记语音锚点和沉默锚点，也可以手动「📌 标记锚点」并关联最近一张还没标记的 PPT 照片。照片最长边压到 1024 像素，最多 50 张。音频、波形、锚点、照片和笔记时间戳写在工作区 JSON 的 `state.lecture` 里。0.1.13 补上了系统选图（`onShowFileChooser`，`image/*`，可多选）和麦克风权限请求的时机。宿主快照上限仍是 32MB。

0.1.14 的源码又加了三处界面，**0.1.13 的 APK 里还没有**：

- 上课录音栏有一枚「翻译」勾选。勾上或取消都会写入课堂会话，并提示「已开启实时翻译」或「已关闭实时翻译」。它只保存这个开关，没有把语音或笔记送去翻译。
- 普通记事本可以自由涂画：画笔、橡皮、深色 / 棕色 / 蓝色 / 红色 / 绿色、撤销、清空，以及回到文字。笔画放在工作区快照的 `drawStrokes`，按钮只在记事本模式出现。
- 启动页改成深色，背景用 CSS 动画画了几道下落的流星。

构建脚本 `tools/build-studio.ps1` 现在写出的文件名是 `dist/Ember-Studio-0.1.14-debug.apk`（共存包带 `-parallel`），versionName 0.1.14、versionCode 22。仓库里还没有打出这两个文件。

## 物理工坊

物理工坊在 `PhysicsJourney.java`。中山大学东侧有建筑「格物堂」和物理学者程理（约在 1180, 480）。靠近程理交谈，或站在格物堂（1200, 540）附近点「进入物理工坊」，即可进入。五关依次开放，每关 1536×1152。格物堂面板只展示进度和已发现的原理，不能点选跳关。过关后走到出口，可以选择下一关或回城；没过关也可以从出口回城，当前机关进度会留下。

界面目标文案写着「调整角度和力度」。抛体的角度和力度在代码里固定为 45° 和 50，没有改这两个数的操作。通关对话和格物堂面板会写上该关原理。城镇目标文案写着「在札记回看发现」，主札记页仍是原来的城镇、身体或数学页面，没有单独的物理札记。

| 地图 | 玩家要做的事 | 首次奖励 |
| --- | --- | --- |
| 抛体靶场 | 走到发射点（300, 800）按攻击。弹按 45°、力度 50 飞出，命中 3 个靶 | 80 金币、生命上限 +10，并恢复 25 生命 |
| 光路迷宫 | 靠近镜面按攻击，每次转 45°。光线需要落到终点附近 | 110 金币、生命上限 +10，并恢复 25 生命 |
| 回路工坊 | 在 6 个节点之间按攻击接线，7 条边全部接上即过关 | 140 金币、生命上限 +10，并恢复 25 生命 |
| 波的干涉 | 走进波源把它推开。两个波源相距 400–600，并保持约 3 秒 | 170 金币、生命上限 +10，并恢复 25 生命 |
| 热流迷宫 | 热源保持 100、热汇保持 0，站在格子上会加热那一格。中心温度接近 50 并保持 3 秒 | 200 金币、生命上限 +10，并恢复 25 生命 |

五关合计 700 金币、生命上限 +50。已经解开的关不会再次发奖；「重新开始」只重置还没过关的机关。第五关的过关札记写着「共振法杖·改已解锁，它能引发连锁共振」。武库仍是原来的六类武器，这句文字没有改解锁状态。

物理进行中，右上角有札记和地图。0.1.14 源码在左下加了「返回城镇」，直接回到格物堂前。0.7.1 和天工 0.1.13 的包是在这颗按钮之前打的，回城仍走出口对话，或打开格物堂面板上的「返回城镇」。

## 试玩反馈与 0.1.14

试玩之后改过操作，这些改动已经在 0.7.1、重打过的 0.7.0 标准包、桌面 jar 和天工 0.1.13 里：

- 暂停菜单点面板外的空白会继续旅程，面板底部写着「点击面板外的空白处，或按手机返回键，随时回到旅程」。返回键本来就可以关掉暂停。
- 右上角暂停入口改成更宽的「菜单」。札记和自动攻击开关也加大了。
- 非体内布局的战斗圆钮可视半径：普攻 45→52，星火斩 34→41，闪避 29→35，药剂 24→30。体内布局的普攻、技能、闪避、药剂和爆发也加大，并挪开全身图。
- 还没有存档时，标题底部写着：第一次玩？先看「旅者手册」了解操作，再出发。从天工进游戏时，标题右下角改为「按手机返回键，随时回到天工编辑器」。直接打开游戏包时，标题右下角仍写着 `v0.7.0`。

0.1.14 源码还在城镇西南放了三位开发者，可以交谈，没有任务和奖励：朱华鸿（180, 700）、李梓宁（280, 820）、伍子安（400, 780）。现有 APK 里还没有这三个人。上面的翻译开关、记事本绘图、启动页流星和物理 HUD 返回按钮同样只在源码里。

## 横屏与窗口适配

游戏世界按窗口实际宽高填满绘图区，像素保持等比缩放；宽屏扩展水平视野，4:3 平板扩展垂直视野。移动摇杆贴近左下、战斗按钮贴近右下，任务与状态贴近顶部；对话、武库等窗口居中。触控和角色点击采用同一套视口坐标，支持刘海安全边距。

Android 30 以上使用 WindowInsetsController 沉浸模式，旧版保留全屏标志；允许短边刘海区域绘制并将交互 UI 放在安全区。应用声明为可调整大小窗口。已生成 16:9、20:9、超宽屏、4:3 和 16:10 的桌面渲染/输入检查，仍需要手机安装反馈。若手机厂商在系统层强制兼容比例或显示悬浮窗口，应用不能保证覆盖系统保留区。

## 武库与战斗玩法

点击左侧「武库」或按 B 打开并暂停战斗。六类武器可以切换，拥有各自的普攻范围、速度、倍率、技能与像素图标；Q 快速轮换已解锁武器。通关或拾取武器空投逐步解锁，旧版体内存档按进度补齐相应解锁。

| 武器 | 普攻与技能 |
| --- | --- |
| 星火剑 | 均衡扇形斩击，三连击末段增伤；旋刃风暴 |
| 疾风双刃 | 高速近战；突袭位移并获得短时护盾 |
| 血晶长枪 | 长距离窄扇突刺；三束可贯穿弹丸 |
| 脉冲弩炮 | 有飞行时间的远程弹丸；三向齐射 |
| 共振法杖 | 三发扇形法弹；大范围共振震荡 |
| 镇域重锤 | 慢速高伤环形重击；震地攻击和护盾 |

每类武器独立强化，最多 +3，花费 30、55、80 金币，每级提高该武器相对基础攻击的倍率。首个武器空投仍保留原有攻击 +4 奖励，同时解锁对应武器。射弹遵守器官墙体、敌人碰撞与穿透次数，并保存飞行状态。

击败敌人积攒爆发能量，满 100% 后点击「爆发」或按 R，造成近域范围伤害并获得 4 秒护盾。护盾减免 55% 伤害；爆发本身击败的敌人不会为本次爆发立即充能。药剂、闪避、升级三选一和原有永久局内成长保留。

## 隐藏相遇：奶龙

奶龙藏在中山大学一处偏僻角落，会沿小范围路径散步、停留；不会预先出现在任务目标、小地图或人物名单中。靠近后它会停下来，玩家可使用交谈按钮、直接点击角色或按 E 开始对话。

先选择愿意坐下来倾听，再在后续对话中给予安慰，完成「角落里的朋友」。玩家可以中途离开、稍后继续，没有惩罚。首次完成获得 **60 金币** 和 **暖心护符：本次旅程生命上限 +15，同时恢复 15 生命**。重复对话、回城、死亡、重启均不会重复发放奖励。成为朋友后奶龙会挥手，并有新的日常台词。

发现后札记才会记录相遇及进度，护符效果在战斗中继续生效。位置、巡游进度、已倾听/已安慰状态保存；开启全新远征才会重置这段相遇及局内成长。对话是本地编写的中文选项剧情，目前没有开放式 AI 聊天。

角色像素素材依据用户提供的奶龙图片，经内置 image_gen 生成，保留透明背景。游戏素材为四帧 64×64 精灵，包含站立、两步行走与开心挥手。[素材与完整生成提示词](docs/NAILONG_ASSET.md)。

当前区域净化后，返回出生点附近的血管转运门，选择前往下一器官或回据点。返回据点可补给，再从北门继续。普通掉落在进入下一器官时统一结算经验、金币与生命；未拾取的器官空投会留在原区域，当前版本不支持重返已完成区域，请在离开前拾取。

五种 Boss 拥有不同像素造型和攻击逻辑：气旋噬菌体追踪预警后冲撞，棘冠孢王释放环形弹幕，脉冲猎手发射高速扇形齐射，增殖巢母召唤不计入基础清除数的增援或震地，神经执政者释放旋转双速弹幕。每个副本都有守卫，生命低于 60% 时缩短攻击间隔，进入狂暴。

0.7 的新生成普通敌人生命提高 35%，首领基础生命提高 65%；追击速度提高 25%（疾行型为 30%），体内受到伤害提高 25%，刷新间隔缩短。旧存档中已存在的敌人保留其血量，后续生成使用新数值。该难度已通过逻辑回归，实际体感仍需试玩反馈。

## 空投与全身图

每个器官累计第 4 次击败触发药品空投，第 8 次触发武器空投，最终区域的武器阈值为 7。药品与武器各一箱，死亡重试不重置已触发或已领取状态。

空投有落点光圈、降落伞和 2.6 秒下降过程。落地后靠近到 19 世界像素内自动拾取：药品补充一瓶药剂，并直接恢复 25% 生命；武器增加 4 攻击并解锁相应武器类型。空投需要实际拾取，不会在触发时直接到账。满药袋时直接回血仍生效，但不会突破容量上限。

右下角全身病灶图显示红色待净化、金色当前、绿色已净化区域；点击可展开血管路线和副本解锁状态。右上角保留当前器官小地图。全身图、对话、札记和升级选择会暂停战斗。

## 死亡与恢复

死亡弹出 **《病入膏肓》**，显示当前器官、伤害来源、用时和击败数量。选择「回中山大学重整」，重置当前未完成副本的敌人与波次，保留等级、强化、装备、金币、净化记录和奖励归属，恢复生命并至少保留一瓶药剂。正常回城会暂停而不是重置战斗和空投。

## 存档兼容与验证

存档写入格式 7，文件头仍是 `0x575A5052`。加载接受版本 1–7。格式 1–5 沿用原先的字段：旧森林存档继续原剧情；0.3/0.4 已完成五站的体内存档保留金币、护符与旧奖励，并从血管继续新增三站。新旅程保存器官、空投位置和下降时间、装备、净化及奖励状态，以及隐藏伙伴的漫步位置和友情进度。Android 使用原子写入，每五秒、触控状态变化及应用离开时保存。武器解锁、独立强化、爆发能量和友方飞行弹丸也会保存。格式 6 起在这些字段后写入数学机关、领奖状态、名字与特效；格式 7 在数学段和名字之间再写入物理工坊的关卡、领奖和机关状态。版本号小于 7 时新建一份空的物理进度。近期脚印和战斗特效为瞬时画面，不进入存档。旧版本不能读取格式 7。

格式 6 和 7 的加载在读完数学（以及格式 7 的物理）之后，还会进入 `readProfileExtras` 再读一遍。这一遍和写入顺序对不上，仓库里也没有格式 7 的往返测试。0.7.0 说明里「能读取格式 1–5」仍然对得上当前分支；格式 6 的续档不要照那句话直接套到 0.7.1。

0.7.0 发布时共 **354 项逻辑检查**（战斗 33 + 城镇剧情 48 + 体内篇 101 + 隐藏伙伴 39 + 扩展 69 + 0.7 专项 64），覆盖实际移动通关、走弦失败、重复桥失败、接缝镜像与朝向、奖励防重复、中途存档续走、双主题切换、旧格式 1–5 迁移、名字与安全区操作。试玩反馈那次提交把套件改到新的按钮位置，并加上 3 项暂停菜单检查，提交说明记为 357 项游戏检查。物理工坊和 0.1.14 的界面改动没有单独的测试类。`tools/verify-release.py` 仍按 0.7.0、versionCode 7 和 354 项来断言。

`artifacts/screenshots-v0.7/` 共 49 张共享 Java2D 渲染预览；39 为扩建东庭，40 为主题选择，41–43 为数学关卡，44 为发现札记，45 为改名，46–49 为挥剑/突刺/挥锤的不同姿态。试玩提交按新按钮重绘过其中若干张。它们是可复现演示状态，不是手机实拍，也没有物理工坊的画面。日志：`artifacts/verification-v0.7.log`、`artifacts/apk-build-v0.7.log`、`artifacts/apk-parallel-build-v0.7.log`。

试玩反馈已经改过暂停菜单和触控尺寸。仓库里的自动检查仍是桌面逻辑和浏览器复测。覆盖升级、帧率、音频、真实麦克风和实际多点触控还没有写进这些记录。当前是可玩的离线原型，尚未加入 AI 自动生成关卡、医学知识判分、器官重复挑战或联机。新横屏布局需要在用户手机上复核。

## 构建与素材

使用 Java 17、Android SDK Platform 34、Build Tools 34.0.0：

```powershell
.\tools\verify-desktop.ps1
.\tools\build-apk.ps1
.\tools\build-apk.ps1 -ParallelInstall
python .\tools\package-source.py
```

Linux 上 `tools/verify-desktop.sh` 对应桌面检查。`tools/build-apk.sh` 的步骤相同，但版本戳还停在 0.7.0 / versionCode 7，输出文件名是 `WuziPing-Emberbound-0.7.0-*.apk`，并会用这些文件重写 `dist/SHA256SUMS.txt`。要得到 0.7.1，用上面的 PowerShell 脚本。可用 `SDK_ROOT` / `JDK_ROOT` 指定工具目录。

天工用 `tools/build-studio.ps1`。前端和检查步骤见 `studio/README.md` 的构建一节；脚本里的版本戳已是 0.1.14，那份说明里的 0.1.12 文件名还没改。

可用 `-SdkRoot` / `-JdkRoot` 指定工具目录。打包复用 `build/manual/debug.keystore`，源码包排除签名私钥、缓存和本地存档。用于真实发布前应配置专门的发布签名。

数学场景通过 `MathRenderer.java` 的绘图接口生成。器官素材通过 `tools/generate_body.py` 用 Pillow 绘制；原有素材生成器为 `generate_assets.py`、`generate_town.py`。原有城镇、战斗贴图和音轨为项目程序绘制/合成；新增奶龙素材。

隐藏伙伴逻辑为 `TownGuest.java`；素材打包脚本为 `tools/pack-nailong.py`。主要体内篇代码：`BodyJourney.java`（副本/剧情/奖励/空投）、`BodyRenderer.java`（体内场景与全身图）、`BodyNavigation.java`（器官地图寻路）。物理工坊在 `PhysicsJourney.java`，城镇入口在 `Town.java` 与 `Story.java`。战斗粒子、震屏和拖尾在 `Vfx.java`，不进入存档。历史设计见 `docs/DESIGN.md`，0.7.0 的变更见 `docs/UPDATE_0.7.md`，武库记录见 `docs/UPDATE_0.5.md`。
