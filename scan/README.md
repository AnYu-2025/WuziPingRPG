# 扫描相机 2.4.0

原生 Android 纸质文档扫描工具：多页拍摄、四角校正、离线中文识别，合成可搜索的 PDF 和文字文件。
支持 Android 10（API 29）及以上。全部图像和 OCR 处理在手机本地执行。

## 安装与升级

安装根目录的 `扫描相机-v2.4.0.apk`。正式包沿用原签名证书，版本号 2.4.0，versionCode 29。
从 2.3.0 升级请直接覆盖安装，保留应用数据；不需要先卸载。

```powershell
adb install -r 扫描相机-v2.4.0.apk
```

旧安装包 `扫描相机-v2.3.0.apk` 保留为版本基线。安装包签名、哈希和权限见 `安全声明.md`。

## 使用入口

| 操作 | 入口 |
|---|---|
| 拍照 | 底部快门；音量键也可拍摄 |
| 自动拍摄 | 顶部「自动」；检测到页边且稳定约 900ms 后拍摄，场景变化后重新准备下一次 |
| 批量导入 | 「相册」，单次最多 100 张，系统选择器也可能施加更低上限；支持进度及取消 |
| 检查页面 | 点缩略图，左右切页，双指放大至 6 倍、单指平移、双击放大/复位 |
| 比较增强效果 | 页面预览顶部选择原色、灰度或黑白；仅改变预览，不改写页面 |
| 重裁 / 旋转 / 还原 | 页面预览底部按钮；重裁从保留原图开始 |
| 排序 | 长按拖动缩略图；页序会保存，重新打开仍保留 |
| 回收站 / PDF 历史 / 反转页序 | 长按「相册」打开文档管理菜单 |
| 快速打开回收站 | 长按「清空」（有页面时显示） |
| PDF 自定义文件名 | 长按「生成 PDF」 |
| 增强图片导出 | 顶部后期处理面板底部；应用当前灰度/黑白/原色与增强设置 |

自动拍摄的场景变化判断属于启发式检测：光照变化、手部遮挡或移动手机也可能触发重新准备。手动快门始终可用。

## 拍摄与裁边

- CameraX 后置相机取景，手动快门可连拍 3 张并按清晰度选优；音量键和自动拍摄使用单帧。
- 实时框与照片「智能选中」共用 Otsu、连通域、凸包及最大面积四边形算法。
- 四角校正支持放大平移、旋转，限制交叉或过小的选框；统一处理 EXIF 旋转与镜像方向。
- 开启双页拆分后，在宽幅画面中检测明显中缝，输出左右两页；没有可信中缝时保留整页。
- 支持双指变焦、转盘精调、点按对焦测光、双击请求锁定/解除曝光与对焦、手动闪光灯及暗光自动开灯。
- 拍摄、处理、导入、预览与导出之间使用互斥状态，减少连点引发的重复任务。

## 增强、识别和导出

- 三种模式：原色、灰度、黑白。灰度/黑白支持对比增强、锐化；黑白使用局部自适应二值化。
- 分辨率长边：自动、2400、2800、3200。拍摄处理和 PDF 合成内存不足时逐档尝试降低到 2400 / 1600。
- PDF 页面可选 A4 或原始比例，文件保存在 `Download/扫描相机/`。
- 离线中文 OCR 使用随包模型，无需下载模型；有文字时叠加文字层并尝试附带同名 TXT，TXT 带分页标记。
- 关闭 OCR 时不读取文字缓存。缓存包含实际处理尺寸，切换分辨率不复用旧坐标。
- 结果会显示已识别页数、未识别页码及 TXT 保存状态；可复制全文。有未识别页时不自动清空页面。
- 导入、PDF 和图片导出均有取消入口。导入在当前照片完成提交后停止；PDF 在处理检查点及写入时停止，OCR 等待期间定期响应取消。
- PDF 未完成输出会清理；图片导出取消时保留已经完成的图片并报告数量。
- 历史 PDF 支持搜索、打开、分享、重命名及确认删除；重命名/删除同时尝试处理同名 TXT。

PDF 搜索与复制效果还取决于阅读器，建议使用支持文字层的阅读器验证。OCR 没识别出文字可能源于空白页、图像质量、超时或模型失败，不等同于文件导出失败。

## 页面存储与恢复

- 页面、原图、待确认拍摄、回收站分别存于应用私有 `pages/`、`originals/`、`staging/`、`trash/`。
- `page-order.txt` 保存稳定文件名顺序，采用临时文件及原子替换提交。
- 兼容恢复 2.3 的 `page_`、`capture_`、`burst_` 页面；未登记文件会对账补回，旧批量导入序号按自然顺序恢复。
- 新版中断的未确认拍摄可在下次启动后进入回收站找回，不再直接删除。
- 单页删除可立即撤销，也能在回收站按页或全部恢复；按删除时间保留 48 小时，在启动时清理过期项。
- 单页保留拍摄/导入原图，双页保留各自分片作为重裁底图；2.3 已经删除的原图无法补回，首次编辑时以现存页面建立基线。
- 卸载会清除私有页面与原图，公共下载目录里的已导出文件由用户管理。

## 本机构建

使用 JDK 17、Android SDK 34、Gradle Wrapper 8.7、AGP 8.5.2、Kotlin 1.9.24。
`local.properties` 配置 SDK 路径；此工程已配置中文 Windows 路径兼容选项。

```powershell
.\gradlew.bat --offline --no-daemon regressionCheck assembleDebug assembleRelease lintDebug lintRelease
```

首次构建若没有依赖缓存，去掉 `--offline`；Wrapper 自身缺少 Gradle 发行包时仍需下载。

- 正式产物：`app/build/outputs/apk/release/app-release.apk`。
- 调试产物：`app/build/outputs/apk/debug/app-debug.apk`，包名为 `com.scan.camera.debug`，可与正式版共存，数据独立。
- `regressionCheck` 运行纯 JVM 行为回归，不需要手机或额外测试框架。
- lint 启用错误中止及 Release 检查，报告在 `app/build/reports/`。
- 正式构建需要已有 `keystore/scan-camera.jks` 和 `keystore.properties`，不允许回退 Debug 签名；不要把签名配置与源码一起公开。

本次升级前的源码快照位于 `backups/source-v2.3.0-before-v2.4.0.zip`，不含签名密钥。
新版变更与验收边界见 `2.4.0_更新与验收.md`。
