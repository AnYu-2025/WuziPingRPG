# 扫描相机 2.4.0：更新与验收

日期：2026-11-02。正式包 `com.scan.camera`，版本号 2.4.0，versionCode 29。

## 本版实现

| 功能链 | 2.4.0 的改动 |
|---|---|
| 拍摄 | 明确拍摄/导入/处理/预览/导出互斥；音量键忽略长按重复事件；连拍评分及缩略图解码移出主线程 |
| 自动拍摄 | 按稳定时间约 900ms 判断，不再依赖固定帧数；拍摄后等待场景变化再重新准备；失焦窗口和忙碌时不触发 |
| 变焦 / 对焦 / 闪光 | 转盘使用相机实际最小/最大倍率，支持可用的低于 1× 倍率；双击通过 Camera2 请求曝光锁；无闪光设备禁用闪光按钮 |
| 页边检测 | 实时与照片智能选中共用轮廓算法；修复 Otsu 阈值等号把背景归入纸页的问题；工作区同步保护 |
| 裁边与方向 | 统一 EXIF 旋转及镜像；四角防交叉/退化；旋转后重新排列角点，避免透视变换把旋转抵消；保存裁边页状态 |
| 页面检查 | 6 倍放大、平移、双击放大/复位；原色/灰度/黑白效果比较；新增重裁、旋转、还原入口 |
| 页面存储 | 新增 PageStore；稳定页文件和原图分离，原子写入页面及页序；关闭校正拍摄也正式提交，不再重启清理丢页 |
| 恢复与排序 | 页序持久化；兼容旧 page/capture/burst 文件；批量序号按自然顺序恢复；旧数据与磁盘对账；支持反转页序 |
| 回收站 | 按删除时间保留 48 小时；单页删除可撤销，也可浏览回收站逐页/全部恢复；中断拍摄可找回 |
| 相册导入 | 单次请求上限提高到 100（受系统上限限制）；逐张进度、失败计数及取消；同一张的分片顺序提交，不残留未拆原页 |
| 增强 | 预览、PDF、图片导出复用同一处理管线；位图失败时清理；拍摄/裁边和 PDF 内存不足逐档降级 |
| OCR | 关闭识别时不读取旧缓存；缓存含实际尺寸、文件大小等；任务结束后回收识别用位图；等待时定期检查取消 |
| PDF / TXT | 实际绑定可取消任务；页间和写入检查取消；未完成文件清理；识别页数、未识别页码、TXT 状态反馈；TXT 增加分页标记 |
| 自动清空 | 存在未识别页时保留页面，方便重试；修复结果弹窗关闭时误清后来新增页面的问题 |
| 图片导出 | 使用当前增强模式和参数，按序补零命名；显示进度及取消，保留已完成图片并报告数量 |
| 历史 PDF | 后台查询、按文件名搜索、重命名、删除确认；同步尝试处理同名 TXT |
| 工程 | Debug 独立包名可与正式版共存；正式签名禁止回退；启用 v2/v3；lint 错误中止并检查 Release；新增纯 JVM 回归任务 |

日志保存在 `verification/build-2.4.0.log`，最终 APK 哈希在 `verification/apk-2.4.0-sha256.txt`。

## 已知边界

- 场景变化检测为启发式，不能保证每次准确识别翻页；实际拍摄成功率需在目标手机和书本上测量。
- 白纸白桌、强反光和弯曲书脊可能无法得到可靠四角；当前为平面透视校正，没有曲面展平算法。
- 已拆双页以各自分片为重裁底图；旧版丢弃的原图无法恢复。
- 识别不到文字时会报告页码，但不区分空白页、超时、模型错误或画质原因；尚无 OCR 文本校对编辑器。
- 导入取消在当前图片完整提交后生效；当前 CPU 图像处理步骤和 PDF 原生绘制不能保证瞬时停止。
- 活动关闭会取消导出；本版没有独立后台导出服务。超大 PDF 仍受 Android PdfDocument 原生内存限制。
- 历史管理受 MediaStore 所有权及权限约束；重命名或删除 TXT 失败会提示操作失败，应刷新列表核实状态。
- 本轮没有建立 Git 仓库。升级前源码在 `backups/source-v2.3.0-before-v2.4.0.zip`，不含签名密钥。
