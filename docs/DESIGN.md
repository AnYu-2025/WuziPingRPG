# 星火远征第一版设计与扩展

本文件记录 0.1/0.2 森林蓝本，0.3 当前玩法以 README.md 和 UPDATE_0.3.md 为准。旧存档继续沿用本文件的规则。

## 当前交付目标

这是一款供团队体验的离线单人二维像素动作 RPG 蓝本。0.1.0 的战斗场景为迷雾森林；0.2.0 从城镇「中山大学」开始，接取主线后进入森林。伍子平携带星火剑进入遗迹，击败逐波出现的魔物，并最终击败遗迹守卫。当前采用局内成长、战果统计保留的规则，完整一局共五波。

第一版从通行的像素动作游戏中选取“移动战斗、拾取成长、选择强化、挑战首领”等规则，具体代码、场景与像素素材在本项目内创建。未使用原神或其他游戏的角色、地图、贴图、音轨。

## 主要规则

| 参数 | 初始值与规则 |
| --- | --- |
| 主角 | 伍子平，星火剑士，等级 1 |
| 生命 | 100；受击后 0.7 秒保护 |
| 基础攻击 | 16，间隔 0.43 秒，近距离扇形范围 |
| 基础暴击 | 8%，1.8 倍伤害 |
| 移动速度 | 每秒 65 个世界像素，斜向移动归一化 |
| 星火斩 | 基础半径 68，攻击力的 2.5 倍，8 秒冷却 |
| 闪避 | 0.18 秒快速位移，0.38 秒无敌，2.6 秒冷却 |
| 药剂 | 初始 3 瓶，恢复一半最大生命，3 秒冷却 |
| 经验门槛 | 9 +（等级 − 1）× 6 |
| 第一至四波 | 分别出现 8、11、14、17 只普通魔物 |
| 第五波 | 一名首领及六只普通魔物 |
| 波间补给 | 恢复 15 生命、补充一瓶药剂（上限 5）、15 金币 |
| 升级 | 三个不重复随机选项，选择一次强化；多次升级逐个结算 |

八种强化分别作用于攻击、生命、移动速度、攻击间隔、范围技能、拾取范围、暴击概率、击杀恢复。增长值和下限已集中在 Game 中，便于根据试玩调整。

## 战斗反馈

角色与怪物有循环像素动画，实体按纵向位置排序；树冠遮挡主角时降低透明度。挥剑显示扇形轨迹，范围技能显示扩散粒子，伤害数值在场景中浮动。普通敌人近身或远程追击，包含简单的障碍绕行和软分离。

首领在重击前显示落点区域，预警结束后才结算伤害；另一种攻击为向四周发射弹幕。玩家可以通过移动、闪避与技能冷却管理完成战斗。当前没有复杂导航网格。0.2.0 已加入城镇、任务 NPC 和主线剧情，具体规则以 README.md 和 UPDATE_0.2.md 为准。

## 工程结构

模拟不依赖 Android，Android 和桌面调试程序共用同一份 Game、Controls、Scene。渲染通过 Painter 接口分别映射到 Android Canvas 与 Java2D。绘制采用固定的 960×540 虚拟横屏视口，按设备比例缩放并保留黑边，触控坐标用同一映射逆变换。

存档采用带魔数与版本号的显式二进制字段，不使用任意 Java 对象反序列化。Android 使用 AtomicFile 写入。当前不进行网络请求，也没有账户或遥测。

## 手机验收事项

安装启动、中文字体与横屏布局、同时按摇杆和普攻、切出应用后继续、冷启动读取存档、背景音和音效开关、至少一局战斗的流畅性、不同屏幕比例和刘海适配。这些项目需要真实 Android 设备，当前未完成。

## 学习玩法的后续扩展

目前没有假接入 AI 或预置“生成完成”的演示。后续应先选一个可以真正影响游戏操作的知识机制，再扩展关卡结构。例如用路线权重控制通行成本、用逻辑条件决定机关状态、用顺序规则控制装置流程。

建议把未来知识关卡独立成数据与规则模块，提供知识依据、可交互对象、条件、结果和提示层级。AI 仅在受约束的规则范围内生成配置，由程序验证关卡可完成；玩法验证后再做资料导入。知识机制尚未定案，本版没有承诺任意知识生成任意游戏。
