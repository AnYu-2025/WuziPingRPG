# 0.3.0 梦入体内

伍子平因病发热后在梦里进入自己的身体。中山大学成为梦境补给据点，六位居民提供任务、剧情、淬火、药品和恢复。新增主线：沈砚接取任务 → 北门血管入口 → 呼吸道 → 肺部 → 肠道 → 肝脏 → 细胞核心 → 血管返回据点 → 沈砚领取终章奖励。

五区有独立器官边界、配色和细节。肠道褶皱参与碰撞，使用缓存流场使敌人绕过长障碍。前三站为三类病毒，后两站为异常增殖细胞，最终核心有红圈预警和弹幕。全身示意图与血管连线显示待净化、当前和已净化，点击查看副本解锁路线。

每个器官第 4 次累计击败空投药品，第 8 次空投武器（终站为 7）。箱子经过 2.6 秒下降，落地后靠近拾取；回城暂停倒计时，死亡不重新发已领箱子。每站第一次完成发 30/45/60/75/120 金币、10 生命上限、一瓶药剂并恢复生命。终章再给 150 金币和攻击 +12 的「星火·免疫之锋」。所有归属状态保存，重复对话或重启不能再次获得奖励。

死亡使用指定标题《病入膏肓》，回据点重整保留成长、净化和领取状态，只重置当前战斗。正常回城则保留实体与掉落。进入下一站会结算剩余普通掉落；空投需在离开前拾取，当前不支持回访已完成区域。

包名和开发签名沿用，版本号提升到 3。存档格式 3 新增固定 195 字节的体内篇状态，同时兼容格式 1、2；旧剧情继续原规则。体验新篇章需要在主界面选择新远征并确认替换当前进度。

验证采用共享模拟器和 Java2D 渲染，具体检查数与日志见 README。所有游戏数值和体内地图为虚构设定；当前无 AI 学习/知识检验，尚未经过 Android 真机安装和性能验证。
