# 0.5.0 血流武库

GitHub 仓库从私有改为公开。新版横屏显示不再以固定 960×540 内容框居中留边：场景使用完整虚拟宽高，UI 使用安全区顶部、底部与左右锚点，对话和武库居中。Viewport 同时被 Android、桌面、Scene 和 Controls 使用，避免只改渲染而触控错位。

Android 30+ 使用原生 WindowInsetsController 沉浸模式，较老版本保留兼容标志；设置短边 cutout 绘制和可调整窗口，并读取 DisplayCutout 安全边距。实现参考 [Android 沉浸模式](https://developer.android.com/develop/ui/views/layout/immersive) 与 [显示刘海支持](https://developer.android.com/develop/ui/views/layout/display-cutout)。厂商的系统兼容模式与悬浮窗口仍可能保留系统区域，需要实机验证。

原五站后增加心脏、肾脏、脑部，独立地图边界、配色、组织细节与小地图。全身图扩展到八个节点。每站均有守卫，共五种原型：冲撞、环形弹幕、快速齐射、召唤/震地、双速旋转弹幕；低生命进入狂暴。副本首次奖励仍幂等。

武库引入六种真实作战类别：剑、双刃、长枪、弩炮、法杖、重锤。可以解锁、装备、轮换和分别强化至 +3。每类普攻和技能不同；远程弹丸有速度、撞墙、命中和穿透状态；近战有三连击末段增伤。击败敌人获得能量，可释放免疫爆发和四秒减伤护盾。原奶龙、对话、存档、药剂、闪避、成长均保留。

存档格式 5，读取格式 1–4。新增区域数组、武器与飞弹尾部；按旧格式读取原五站，而非用新数组误读旧档。已完成 v4 的档保留旧奖励和友情，开放心脏续篇；终章新奖励为 180 金币与攻击 +12。

290 项逻辑检查，37 张预览。宽高检查覆盖 1920×1080、2400×1080、2750×1236、3440×1440、1600×1200、1280×800，加刘海安全区。实际 Android 安装、厂商全屏设置、音频、多点触控与帧率仍待验证。更新代码不等于用户这台手机已经验证消除留边。
