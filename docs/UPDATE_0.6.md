# 0.6.0 星火重绘

这一版不改战斗数值、副本顺序、武器规则和存档字段，只重做能看见的部分。存档格式仍是 5，继续读取 1–4。0.5 及更早的旅程回到标题后可以继续，包名仍是 `cn.wuziping.ember`，横屏、安全区和触控锚点保持原坐标。

界面改成一套墨底、金框、星火赤纹。主菜单留下城镇背景，菜单和旅者卡片加了金角与漂浮火星，档案区可以点开札记。摇杆、普攻、技能、闪避、药剂和爆发按钮改成金边圆键；冷却用刻度环表示，就绪时外圈轻跳。生命、经验和爆发能量有高光。低生命时画面边缘变红。对话名牌、武库卡片和全身图沿用同一套边框，已装备武器用自身颜色标出。

战斗反馈放在 `Vfx.java`。命中和暴击迸发粒子并轻轻晃动画面，受伤有红闪和更明显的一震。近战按武器画出扇形、突刺或重锤拖尾，弩炮和法杖弹丸带尾迹，撞上敌人或墙会爆开。星火斩、武器技能和免疫爆发使用扩散环。伤害数字加了描边，暴击更大。拾取、药剂、空投落地和血管流转也有光点。粒子、震屏和残影只活在当场对局里，`save` / `load` 不写这些字段。

逻辑检查仍为 290 项。桌面预览 38 张，其中 38 专门留给命中、爆发和低生命。Android 真机安装、覆盖升级、帧率、音频和多点触控仍未在设备上验证。仓库里的调试 APK 由构建机新建的 `build/manual/debug.keystore`（别名 `androiddebugkey`）签名，正式覆盖安装需要用原来的开发密钥重签。
