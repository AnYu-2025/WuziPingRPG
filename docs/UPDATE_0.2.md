# 城镇与剧情版本更新

版本 0.2.0，2026-11-02。

城镇名称按用户要求统一为中山大学。新增七座建筑的外景、喷泉广场、集市摊位、长椅、路灯、北门及六位可交谈居民。建筑与喷泉参与碰撞，地图与方向标记提示下一处主线目标。

剧情序章为长夜里的来信：伍子平收到寻找星火的信件，向沈砚接下委托，向阿岚了解情况，进入森林挑战被迷雾侵蚀的遗迹守卫，回城交付星火。知夏提供点灯人的背景故事；陆铸、苏禾和阿满提供强化、药剂与恢复。

界面采用深蓝灰面板、金色角饰、人物头像、统一任务卡与对话框。中文台词逐字显示，支持显示整句、翻页和明确选择，正文按宽度换行。札记显示剧情进度和居民信息。城镇隐藏战斗技能按钮，显示就近交谈入口。

存档版本升级到 2，仍读取版本 1。城镇与森林可以往返，森林中的波次和实体状态暂停保留。失败后返回城镇，保留成长并重置当前波次；主线完成奖励和补给奖励只能领取一次。新旅程才会重置剧情。

81 项模拟检查通过。当前版本没有经过 Android 真机安装与升级测试；渲染图为共享渲染代码生成的桌面预览。新 APK 的签名校验通过，且签名证书与 0.1.0 版一致。
