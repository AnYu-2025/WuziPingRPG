# 0.7.0 规律星庭

基于外部 0.6 的实际提交 f459f7f 继续开发，保留像素 UI、粒子、八器官、六武器与隐藏伙伴。

## 可以试玩的变化

- 中山大学从 960×720 扩展为 1440×1080，增加东庭、星图学舍、花房及数学入口。城镇主题卡可直接进入数学，学者知夏增加引路对话。
- 三幅数学地图均为 1536×1152。通过走位触发真实状态机，没有知识选择题。第一关用等距轨迹连接三灯，走弦会熄灭；第二关要求每条桥恰走一次；第三关通过反向接缝观察位置镜像和局部朝向，并激活对应路标。
- 保留近期脚印、桥梁亮色、小地图与重走入口。首次完成每关分别奖励 60/80/100 金币、生命上限 +8，完成后解释原理，领奖不可重复。
- 身体与数学探索互相冻结战斗，不清空敌人或弹丸；只在安全城镇切换主题。
- 标准人体图在缩略图与大图中均按 160:240 原图比例等比居中。
- 主界面改名，默认伍子平；最多 12 个 Unicode 字符，输入清理控制字符，支持空值恢复默认。新旅程保留名字与特效设置。
- 六武器围绕握点显示实际姿态变化：剑/双刃/重锤旋转，枪沿朝向突刺，远程武器后坐。挥动拖尾与方向同步。柔和特效减少粒子和闪屏、降低震屏与低血量脉动，设置独立于声音。

## 人体篇难度

新生成普通怪生命 ×1.35，首领基础生命 ×1.65；追击速度 ×1.25，疾行怪 ×1.30；所受伤害 ×1.25。刷新间隔从 max(0.65, 1.6-器官序号×0.12) 调整为 max(0.42, 1.2-序号×0.10)。

首领在 60% 血量进入狂暴，攻击间隔更短；孢王环形弹幕增密，部分齐射加速。保持伤害预警、闪避、药剂、补给和奖励。旧存档已有敌人的生命不会在读取时暗中重写。数值仍需真机试玩平衡。

## 数学验收依据

实际输入移动路径完成三关；验证走弦与重复走桥不能通过。桥梁交叉口按最近的相邻边选择，防止合法斜向走位误选旁边的桥。检查两次反向接缝后恢复局部朝向，错误朝向不能点亮标记。第一、第二关分别检查中途存档与续走，避免仅测试直接修改完成标志。

拓扑长廊是接缝坐标模型，不是连续的 3D 莫比乌斯曲面；箭头是局部坐标朝向，不能解释为两张面。当前关卡为手工设计的独立探索原型，没有 AI 自动生成或数学主题战斗 Boss。
