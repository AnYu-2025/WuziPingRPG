# 0.4.0 角落里的朋友

新增用户指定角色「奶龙」的隐藏城镇相遇。角色像素化保留黄色胖身躯、浅色肚皮、绿色眼睛和短四肢，四帧透明精灵供站立、行走与开心挥手使用。生成源图、打包脚本、提示词均保留在项目内。

奶龙在偏僻角落的小范围路径中慢走停留，遵守城镇碰撞。玩家靠近时发现并停步，支持点击移动中的角色、交谈按钮和 E。它不进入常规人物名单、小地图或主线导航，未发现时札记不透露身份与位置。

友情剧情有三种持久阶段：未倾听、已经倾听、已安慰并领取奖励。中途离开可以再次回来，奖励需要完整选择倾听与安慰，首次完成给予 60 金币、暖心护符（生命上限 +15 并恢复 15 生命）。状态与属性一起写入原子存档，防止重复领奖。之后对话和角色表情变为老朋友状态。

存档格式提升为 4，末尾追加 26 字节伙伴状态；继续读取格式 1/2/3。旧版旅程可直接回镇寻找，无须重开。存档会保存漫步位置、停留计时、目标路点、友情阶段与发现状态。新开远征会重置本次友情与护符属性。

新增 39 项行为检查，旧有 158 项仍通过。共 29 张共享渲染预览，24–29 为奶龙相遇、倾听、安慰、奖励、成为朋友和札记。尚未进行 Android 真机安装与覆盖升级验证。
