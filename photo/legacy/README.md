## v0.11 曲线 + HSL（单测已验数学）
- RGB曲线：RGB/R/G/B四通道，点线加控制点，拖动调，双击删，S型一拉就有胶片对比；单调三次插值（恒等保真+单调顺滑，单测覆盖）
- HSL八色分调：红橙黄绿青蓝紫品，色相±30/饱和±100/明度±100；余弦平滑权重不留断层
- 调色进撤销/记忆/我的预设全链路；“还原”一键清曲线HSL；切图/导出/批量/视频封面同一管线
- 口语：“蓝色饱和一点”“绿色提亮”“红色压暗”（蓝调/黄昏/印章不串）

## v0.10 视频一期（已双页截屏验收）
- 顶栏 🖼图片 / 🎬视频 页签切换；视频：导入播放（mp4/mov/webm）+ 进度/音量
- 调子共享：图片页调好的亮度对比饱和曝光色温+预设+水印贴纸，视频直接套用；重型效果（锐化/去雾/磨皮/颗粒/雨雾）视频自动跳过保流畅
- 修剪：起止秒输入+取当前点+区间循环试看；画面比例（原/16:9/9:16/1:1）+清晰度（原/1920/1280/720）
- 导出视频MP4（优先）/WebM：滤镜+旋转镜像+水印+原声，带进度+取消；一键导出视频封面（走图片导出设置）
- 口语：“视频模式”“5秒到12秒”“设起点”“导出视频”“视频封面”“回到图片”（“导出视频”不再误触图片导出）

## v0.9 UI 重设计（已截屏验收）
- 深空灰+雾蓝紫渐变，卡片式三栏，顶栏口语框 C 位带聚焦光晕
- 滑杆带进度填充+悬停放大拇指；按钮/输入/下拉全套深色圆角；预设卡片悬停上浮
- 工具栏分组药丸底+分隔线；照片信息变胶囊；滚动条收窄；小屏自适应三栏变窄

## 已有功能（v0.8 完善）
- ⭐ 我的预设：调出喜欢的效果，起个名存下来，本地长期有效，点×删除，也吃预设强度
- 拼图底虚化：缝隙/底不再死黑死白，第一张铺底虚化；网格最多9张（自适应2/3列）
- 照片信息条：文件名｜尺寸｜大小｜相机·光圈·快门·ISO·日期（有EXIF才显示后半）
- 口语 v2.5：新增“背景虚化”“纯色底”
- 🔪 切图（九宫格发圈）：3x3/2x2/2-4行列自选，预览带宫格线+序号
  - 色调质感全吃（滤镜/锐化/雨雾都进分片），水印贴纸不进
  - 导出照片=整图一张；批量打ZIP=分片（原尺寸拼回正好一张，按1-N顺序发即拼回）
  - 口语：“切九宫格”“切图”“切四宫格”（“四宫格”还是网格拼接，不串）
- （v0.6）磨皮柔肤 / 雨丝雾气 / 标题贴纸 / 拖拽排序
- （v0.5）缩放浏览 / 预设缩略图 / 直方图自动增强 / 水印工作室 / 另存为+ZIP

## 已有功能（v0.5 去简陋）
- 浏览：滚轮缩放/＋－/适应/100%/双击适应，三分构图线（裁剪·校正时自动出现），ESC取消裁剪
- 预设实拍缩略图：11个氛围点之前先看效果，换图自动更新
- 色阶：RGB直方图实时显示 + ✨自动增强（一键拉层次+校正偏色，可撤销）
- 单图精修：亮度/对比/饱和/曝光/色温/暗角/颗粒/锐化/去雾 + 旋转90° + 镜像/翻转 + 水平校正(±15°模糊铺底) + 预设强度
- 裁剪：框选+比例+三分线，图片级可撤销（删图/清空/自动增强也可撤销）
- 拼图：横/竖/网格2x2 + 缝隙 + 黑白边框色
- 水印：5档位置/颜色/字号/不透明/描边；调子记忆（下次打开还在）
- 导出：系统另存为对话框；批量打ZIP（一个包带走，原文件名命名）
- 口语 v2.3：新增“自动增强”“放大/缩小/适应窗口”“打包”；“翻转一下”不再误旋转
